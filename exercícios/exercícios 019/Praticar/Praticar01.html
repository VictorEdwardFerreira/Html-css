Como começar na programação

Etapa 1: Lógica de Programação (2 a 4 semanas)

  • Aprenda:
    • Variáveis
    • Condições (if, else)
    • Laços de repetição (for, while)
    • Funções
    • Vetores/Listas

      • Pratique resolvendo exercícios simples de lógica.

Etapa 2: Escolha uma linguagem (1 a 2 meses)

Recomendo começar com Python porque tem sintaxe simples e é usada em várias áreas.

  • Aprenda
    • Tipo de dados
    • Funções
    • Arquvios
    • Tratamento de erros
    • Módulos e bibliotecas
  • Projetos
    • Calculadora
    • Lista de tarefas
    • Jogo de adivinhação
    • Gerador de senhas

Etapa 3: Git e GitHub (1 semana)

  • Aprenda
    • Oque é controle de versão
    • commit
    • push
    • pull
    • branch

      • Crie uma conta no GitHub e publique seus projetos.

Etapa 4: Escolha uma área

  • Desenvolvimento WEB
    • HTML
    • CSS
    • JavaScript
    • Frameworks depois (React, Vue)
  • Back end
    • Python + APIs
    • Banco de dados (SQL)
  • Dados e IA
    • Python
    • Pandas
    • Numpy
    • Machine Learning
  • Mobile
    • Flutter ou Kotlin

Etapa 5: Banco de Dados (2 a 3 semanas)

  • Aprenda
    • SQL básico
    • SELECT
    • INSERT
    • UPDATE
    • JOIN

      • Pratique com PostgreSQL ou SQLite.

  • Rotina sugerida
    • 30 a 60 min por dia
    • 70% prática
    • 30% teoria
    • Criar pelo menos 1 projeto por mes

      • Meta para 6 meses: conseguir criar aplicações simples sozinho e montar um portfólio no GitHub.
