Página 4 — Algoritmos

Um algoritmo é uma sequência organizada de passos para resolver um problema.

Exemplo::

Problema: Fazer café.

Algoritmo:

  • Colocar água
  • Adicionar café
  • Aquecer
  • Servir

    • Na programação, criamos algoritmos para resolver problemas maiores.
