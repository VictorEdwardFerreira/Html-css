Página 2 — O que é Programação?

Programação é o ato de criar instruções para que computadores executem tarefas.

imagine que você quer ensinar alguém a fazer um sanduíche. Você precisa explicar passo a passo:

  1. Pegue pão
  2. Coloque queijo
  3. Feche o pão

    4. Programar funciona da mesma forma: o computador precisa de instruções claras.
