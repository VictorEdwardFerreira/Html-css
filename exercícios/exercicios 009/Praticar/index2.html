Rotina de um programador

De manhã

  1. Acordar (Hora: 08:10 )
  2. Comer (Hora: 08:50 )
  3. Pensar e planejar como vai ser seu dia (Hora: 09:10 )
  4. e começar a programar (trabalhar) (Hora: 09:40)

De tarde

  1. Parar pra descansar um pouco (Hora: 15:20 )
  2. Comer alguma coisa(Hora: 15:40 )
  3. E voltar a trabalhar(Hora: 16:16 )

De noite

  1. Fazer janta(Hora: 20:30 )
  2. Comer(Hora: 21:10 )
  3. Tirar um descanso e revisar as coisas(Hora: 22:30 )
  4. trabalhar por mais duas horas(Hora: 22:40: )
  5. E dormir(Hora: 00:00 )
